# Code editor in Python and tkinter 

---

-  I made this kind of app for low memory usage for my ubuntu and phone based development setup where I use lightweight desktop envoirnment. While connecting my phone to external display via display output ( if your ohone supports) or via screen mirroring and keyboard and mouse wired or wireless

- You need python and the required requirements listed in requirements.txt

- The idea is to be able to simply edit code on the go or otherwise when I dont want heavy linting 

- The aim is for a low memory footprint and smoother code editing experience
